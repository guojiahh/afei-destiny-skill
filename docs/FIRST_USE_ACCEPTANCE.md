## 发现并修复

| 原来的障碍 | 修复 |
|---|---|
| 普通浅克隆仍取回大量历史演示 | 安装入口改为 `--filter=blob:none --sparse`，只检出可安装目录 |
| Mac 只有 `python3`，内部命令却要求 `python` | 首次选定受支持的解释器，后续复用其绝对路径 |
| 计算、会话与 HTML 指令分别假定技能目录或仓库根目录 | 增加统一运行准备；绝对脚本路径与用户工作目录分离，会话路径保持唯一 |
| “一步一步，最后要完整报告”可能被归为一次性模式 | 将交谈节奏与最终交付形式分开，保留分步咨询 |
| 单次或聚焦报告可能缺少技术来源所需的盘面审计 | 明确跳过盲测不等于跳过技术依据；不虚构盲测或反馈 |
| 民用时区容易被误当成独立计算参数 | 明确经度与 UTC 时差成对启用真太阳时校正；不校正时两者都不传 |
| 缺失全部 HTML 素材仍能通过原自检 | 自检增加默认报告文件、运行指南和素材哈希验证；校验完整发行清单，避免清单被截短后漏检 |
| 自检可写性探针使用固定文件名 | 改为临时文件，保留用户已有同名文件 |
| 首次使用说明没有清楚交代报告位置和后续恢复 | 增加分步预期、HTML 绝对路径、打开方式和继续原会话的示例 |

新增五项安装回归覆盖缺素材、素材损坏／缺失、自检不覆盖已有文件、缺运行指南，以及发行清单不完整。工作区检查共 **129 项 Skill 测试 + 6 项评测工具测试**通过，另有七项环境自检、Skill 结构和 Markdown 本地链接检查通过。

## 验证边界

本轮完整对话使用的是虚构材料；它验证安装、来源隔离与交付流程，不验证传统命理的预测效力。宿主发现通过临时项目技能入口验证，没有覆盖用户的全局安装。Windows 安装说明未在实体 Windows 桌面逐步点击验证；跨平台脚本由仓库 CI 检查。

浏览器工具不支持直接打开本地 `file://`，因此仅向本机开放该份合成 HTML 进行预览，未发布到外网。下载自动化接口超时，未确认实际保存到浏览器下载目录；已直接校验页面下载链接的文件名和完整内容。

使用者从[安装与完整报告指南](../afei-destiny-skill/README.md)开始。维护者可结合[运行准备](../afei-destiny-skill/references/runtime-setup.md)与[HTML 交付协议](../afei-destiny-skill/references/html-report.md)复核命令和产物。
