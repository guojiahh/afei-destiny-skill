## 展示策略

当前系统演示只把已经实现并经过验证的能力称为可用；匿名设计样机另行标注，不作为真实咨询或正式生成能力的证据。不陈列早期咨询案例。新的真实案例只有在完整走过现行咨询流程、完成隐私审查并获得公开授权后才会加入。
