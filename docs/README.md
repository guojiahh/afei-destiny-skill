# 文档总索引

这个目录只放“解释项目”的材料；可安装 Skill 在 `bazi-skill-main/`，评测程序和实验原件在 `evaluation/`。

## 先看哪一份

| 你的目的 | 入口 |
|---|---|
| 想弄明白整个仓库 | [工作区地图](WORKSPACE_GUIDE.md) |
| 想知道题怎么做、怎么评分、怎么改 Skill | [评测与迭代方法报告](EVALUATION_AND_ITERATION_METHOD.md) |
| 想安装或调用 Skill | [技能安装与使用](../bazi-skill-main/README.md) |

| 想对外演示 | [三分钟演示指南](SHOWCASE.md) |

## 项目说明

- [工作区地图](WORKSPACE_GUIDE.md)：顶层目录、关键文件、源文件与生成物边界、修改入口。
