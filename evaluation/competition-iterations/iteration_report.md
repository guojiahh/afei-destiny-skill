# 2010–2025 历届比赛错题迭代报告

日期：2026-08-10

## 结论

本轮完成了 GPT-5.6 + 本地 Bazi Skill 对 2010–2025 全部 16 届、107 个案例、515 题的基线覆盖，并完成一次“开发集归因 → 修改 → 回归集配对 → 再收敛 → 一次性保留集配对”的闭环。

最终保留集没有证明 exact-match 提高：旧版 70/160（43.75%），最终版 71/160（44.38%），净增 1 题、+0.63 个百分点；19 题由错变对、18 题由对变错，命例级 bootstrap 95% 区间为 −6.25% 到 +7.50%。区间跨 0，因此不能写“准确率已经提高”。置信度校准略有改善，但不能替代主指标。

## 数据与隔离边界

- 本地缓存包含 2010–2025 共 16 个标准化 JSON、107 个案例、515 题；515 题都有答案，答案键都对应有效选项。含答案 JSON 与原始网页保存在 Git 忽略的 `.benchmark-cache/global-fortune-competition/`。
- 新版 `prepare` 使用显式字段白名单生成题包，删除答案、来源 URL、排盘 URL、作者和回查标识；题包、Skill、固定提示和协议均记录 SHA-256。
- 每个盲答代理使用 GPT-5.6、`high` 推理强度和 `fork_turns=none`，只允许读取单年无答案题包、Skill 与固定 solver contract；预测完整写入后再锁定哈希。
- Codex 子代理仍共享工作区文件系统，因此这只是可审计的输入白名单，不是操作系统级硬隔离。公开题页是否存在于模型预训练记忆中也无法排除；不得声称绝对无污染。
- 2010 的早期轮次在解析调试时接触过部分答案，只算污染训练记录。2011–2012 是旧协议记录；2013 以后使用新版白名单与新鲜子代理。

## 开发集基线与错因

当前 Skill 修改前，2013–2017 的新鲜开发基线为：

| 年份 | 命中 | 准确率 |
|---|---:|---:|
| 2013 | 5/16 | 31.25% |
| 2014 | 9/35 | 25.71% |
| 2015 | 16/35 | 45.71% |
| 2016 | 13/35 | 37.14% |
| 2017 | 16/35 | 45.71% |
| 合计 | 59/156 | 37.82% |

32 个命例宏平均为 39.37%。平均自报置信度 58.61%，明显高于实际准确率；top-label Brier 为 0.2735。

97 道错题全部按固定顺序完成结构化根因分析：

| 主因 | 数量 |
|---|---:|
| unresolved / 低可识别且证据不足 | 55 |
| reasoning_error | 30 |
| execution_error | 6 |
| knowledge_gap | 3 |
| calculation | 2 |
| option_parse | 1 |
| data_issue | 0 |

达到修改门槛的复发内核：

- 具体结果越级，忽略阶段或现实基准率：9 题 / 7 案例；
- 醒目合冲压过整体结构和目标接口：5 题 / 4 案例；
- 复合选项没有按最弱必要子句否决：4 题 / 3 案例；
- 候选年份没有同尺度完整比较：3 题 / 3 案例；
- 紫微斗数大限被错误替换成八字大运：3 题 / 2 案例，只增加路由禁令，不伪造紫微模块。

两个确定性问题中，一个是代理把年龄段映射到错误大运；另一个是计算器在换运年按整年选运，忽略具体日期。后者已经修复并增加边界回归测试。

## 修改内容

1. `calculate_bazi.py` 增加精确 `target_date`；大运周期输出确切起止时刻。整年跨换运边界时同时返回前后两运，不再擅自选一运。
2. `compare_candidate_years.py` 增加 `--candidate-dates`，支持节气前后和换运年的同尺度日期比较。
3. Benchmark 协议增加强制六行决策卡：子句矩阵、主体/领域/阶段、确定性事实、整体功能链、粒度/基准率、最强反证。
4. 明确裁决优先级：题面与子句矛盾 > 主体/领域/阶段 > 确定性计算 > 整体功能链 > 基准率破平。宽泛功能链不能一次证明多个具体经历。
5. 否定题要求正面不相容证据；“命盘不支持”不能当作“现实中没发生”。非八字体系有隔离 BASE 时禁止专家换票。

## 配对回归：2018–2021

| 年份 | 旧版 | 候选版 | 差值 |
|---|---:|---:|---:|
| 2018 | 17/40 | 15/40 | −2 |
| 2019 | 15/40 | 14/40 | −1 |
| 2020 | 9/40 | 13/40 | +4 |
| 2021 | 14/40 | 19/40 | +5 |
| 合计 | 55/160（34.38%） | 61/160（38.12%） | +6 / +3.75pp |

20 题由错变对、14 题由对变错、126 题持平；命例级 bootstrap 95% 区间为 −4.00% 到 +12.03%，仍跨 0。候选版命例宏平均从 33.14% 升到 35.88%，Brier 从 0.3058 降到 0.2735，平均置信度从 58.96% 降到 50.30%。

变化题审计没有支持整条回滚，但发现两类交互回退：整体功能链有时压过复合子句/粒度门槛；否定题把不可识别误当成未发生。最终版据此做了上述裁决优先级收敛。
