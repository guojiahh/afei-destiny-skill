# Iteration 3 analysis

- Development fold: MingLi-Bench questions 71–80, unseen before prediction.
- Predictions were saved before scoring.
- Exact match: 4/10 = 40%.
- Cumulative staged development result: 13/40 = 32.5%.

## Generalizable failure modes

1. Selected “all years” without requiring evidence for every year.
2. Matched a debt outcome but guessed the unsupported dramatic cause (gambling) instead of evaluating the cause separately.
3. For formal marriage timing, direct combination was overweighted while full day-pillar/luck-cycle repetition and landing conditions were underweighted.
4. Education inference overused modern location base rates and underused the actual learning chain and age/status wording.
5. Multi-question consistency helped career and personality, but should not become circular proof.

## Revision

Added option decomposition, negation handling, conjunctive-evidence burden, cause-specific scoring, detail penalties and a clearer distinction between meeting, relationship change and formal marriage. No benchmark item or answer was added to the installable skill.
