# V20 一次点击反馈验收

日期：2026-10-20。对象为本目录的合成求职演示及共享 Skill 模板。

## 浏览器实际操作

在 macOS Chrome、1470 × 702 桌面视口中，分别点击三个选项：

| 选择 | 实际观察 |
|---|---|
| 材料够了，先投一份 | 单击后沿原光点线自动前进，三句反馈依次出现；走完自动停下，原诗卡和结果留在右侧。 |
| 还缺一项，就把它补清楚 | 叶片转场退出后开始走向母树；有限光点收集后枝条舒展，周围草地变亮，停下并留卡。草原母树的原图集终态是裸枝，不是绿叶树冠。 |
| 留给时间跟坚持 | 叶片退出后自动前进，原纸片跟随、白色花草短时生长；停止前进后保留原诗卡与结果。花草仍遵循原引擎的短时生命周期。 |

不要求点击“继续尝试”或长按。播放结束后才提供可选重播。
第一项实际暂停时进度为 `0.03375000000000001`，经过其他操作后读取仍相同，继续后完成。
原此刻／来处仍由按住控制，选择阶段不再依赖按住。

快速点击第二、第三、第一、第三项，最终实测为 `tundra / done / progress=1 / transitioning=false`，
选中第三项，纸片、花和结果一致。验收期间浏览器错误日志为空。

## 本轮实际发现并修复

- 右侧选项挡住第二项的最后一句：世界锚点保持不变，屏幕投影在选项左侧收边；窄屏在面板上方收边，长句换行。
- 草原转场尚在退出时立即发起下一转场会复用原 Svelte 组件，使后一次换景缺少挂载计时。适配层等待原 store 标志清除、叶片容器真正卸载，并经过一个正常世界帧，才消费最后一次选择。首句反馈也在叶片退场后开始。
- 冻原暗色地面下标题和底部说明不清楚：沿用其他场景的浅字与柔和深色阴影；减少动态的静态阅读继续使用深字。
- 首屏 HTML 的旧导航顺序已同步为“此刻／来处／可能”，避免初始化前闪过旧顺序。
