# 此后 · 第一阶段回环与积累演示

依据[产品方案](../../docs/CIHOU_PRODUCT_PLAN.md)第一阶段制作；本次按 2026 年 10 月 16 日追加反馈，精修循环型主图的空间感、反复留痕、自动讲解与完整报告的阅读层次。第二阶段未启动。

打开[当前独立 HTML](../cihou-stage1.html)。[改版前完整原型](../cihou-stage1-v1.html)和[更早的概念演示](../cihou.html)保留用于对照。当前文件不依赖外部字体、图片、库或接口，可以直接打开。

**当前四个案例都是人工定制的体验样机。** 可以沿用阅读框架、视觉语言和交互规则；每次咨询的主问题、经历、关系、行动、主图结构和讲解内容需要由本次材料决定。当前尚不支持同一图形类型下的多个独立人物，也未实现任意节点数量的布局或按咨询选图。

不能只替换姓名或 `cases.js` 就生成另一个人的报告：`interactions.js` 的文字与来源引用、`experience.js` 的补充自述仍按图形类型绑定现有案例，`scene-kinetic.js` 的任务回环与自动分镜也专为林舟设计。新对话先按[工作交接](../../docs/CIHOU_HANDOFF.md)模拟完整咨询，再核对资料适合什么图；不预设每个人都应使用循环图。

## 阅读方式

来处、当下、尚未发生的条件分支同时出现在主图中。反馈环、接桥、汇流三个案例各有 **6 个图内热点**，信息不足案例有 **4 个热点**；可以直接点任意位置，不需要按顺序完成。图下只保留一处解释，随所选热点更新；重复点同一热点可重播局部动效。没有图外预演按钮、弹窗、切页或依赖悬停的入口。

热点只改变阅读焦点和图形强调，不改写案例事实、现实行动状态或观察草稿。行动热点引入一个可讨论的条件，断口仍停在等待现实回应之处；条件情景不登记为已经发生。林舟样例首次自动讲解约 16 秒：来处、反复、此刻、介入，随后停在等待回应。可暂停／继续／重播，点图内任意位置立即接管。页面进入后台或主图离开视口时暂停，回来不会补跑；减少动画设置下不自动播放。其余三种图保留直接探索方式。没有声音或滚动劫持。

向下直接阅读五段：

1. **来处：**完整已有叙述 → 当前理解小图 → 默认可见的最强反例 → 决策场景对照 → 命理解释层及缺依据状态。
2. **此后：**行动改变什么 → 投入与外部条件 → 两种条件情景 → 暂不行动的选择 → 已知时间窗口。
3. **全貌：**八领域覆盖一览、已谈到的全部主题要点、仍未展开的部分；默认可见。
4. **重看：**预先写好的虚构反馈 → V1、V2 直接对照 → 保留、修正与未知项。不会切换整份报告，也不会跳回顶部。
5. **带回生活：**一个观察问题；需要时展开记录或纠正并导出。

正文显示八主题的实际覆盖内容；完整来源、关系条件和 V2 依据仍可在附录核对。林舟追加 L4–L6 三条明确标注的虚构自述，分别展示决策顺序、价值与反例，不新增主图因果边、不覆盖 V2 修正，来源也写入观察导出。记录、分享和样例选择放在阅读末端，不占主图入口。样例切换仅用于原型比较，正式个人报告不包含其他人的资料。

## 视觉与参考

新版本采用暖白纸面、墨色中文标题、蓝色立体回环与铜橙色行动拨片。循环图有宽轨道的切面、前后遮挡、任务薄片与等待台；薄片沿回路移动并留下叠层，行动把下一份任务转向讨论，旧积压保留。回边标明“再次承接？”，没有负荷评分或真实次数。桌面与手机分别构图，并裁去无用空白；正文在手机按阅读顺序单列展开。

循环型通过独立的 `scene-kinetic.js` 替换主图，其他三种类型、V1/V2 对照与分享画面暂沿用原线束版本。没有把个人内容烘焙成背景图，也没有增加图片或外部运行库。完整产品结构与后续类型库见[报告体验方案](../../docs/CIHOU_REPORT_EXPERIENCE.md)。
热点由 HTML 原生按钮覆盖在图内，命中区约定为 `96 × 56` CSS 像素，支持点按与键盘激活，无 hover 依赖。主图保留同一 SVG DOM，通过同一组图形部件变换与有限路径动画表达状态。循环图暂停保留过程；重播、切节点、切案例会取消旧的叙事时钟。

本次考察了 Awwwards 的作品及制作方资料，具体取舍见[设计研究与实现记录](DESIGN_NOTES.md)、[年度作品和动效选型研究](ANNUAL_AWARDS_RESEARCH.md)与[动态叙事研究](KINETIC_RESEARCH.md)。研究区分年度获奖证据、作者描述、文章视频与实际原站观察。当前选用原生 SVG 与控制点插值，保持单文件离线交付，无需 CDN；GSAP、Motion、Anime.js 的功能和许可比较保留在研究文档中。没有复制参考网站的图像、字体、脚本或品牌资产。

## 内容与边界

所有姓名、经历、关系与回访均为匿名虚构创作，未读取真实咨询、出生资料或评测内容。图形不是历法或八字结论。线数、长度、颜色与位置没有评分、概率或因果强度含义。

| 样例 | V1 节点／关系 | V2 节点／关系 | 修正内容 |
|---|---|---|---|
| 林舟 | 3／3 | 3／2 | 回环改为岗位空缺与明确派工的开放链 |
| 许宁 | 5／4 | 5／4 | 已有作品被确认，缺口移至标准与具体反馈 |
| 乔安 | 7／6 | 7／5 | 合作条件尚不具备，移除共同投入连接 |
| 知夏 | 2／0 | 2／0 | 没有新增依据，不补原因与未来分支 |

记录区明确对应 **V1**，上方 V2 是独立的模拟回访。草稿按案例隔离，仅存于页面内存，刷新清空；未导出的修改触发离开提醒。“已在现实中尝试”需手动选择并填写实际行动。图内热点与局部重播不会改变记录状态。导出后仍需由用户带回原咨询。

分享文件由结构枚举、行动短句和三个显示开关重新生成，不接收完整案例。关闭的内容从 SVG 源码中移除。导出优先 PNG，失败降级 SVG。完整演示 HTML 含全部虚构案例，不应作为正式个人分享文件。

现有 Skill 已有咨询 Harness、双 Markdown 报告登记与失效机制。尚未实现的是正式 HTML 生成器、HTML 所需的 Harness 扩展和路由登记与失效支持，以及私有在线阅读器、真实跨设备交付。本原型没有接入这些 HTML 能力。
