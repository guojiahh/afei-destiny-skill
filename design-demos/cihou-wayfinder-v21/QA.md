## 真实浏览器操作

使用 Codex 内置浏览器，打开本机 V21 HTTP 开发预览。视口覆盖 1280×720、390×844、390×700、390×667 和 320×568；这里的窄屏为浏览器视口验收，未进行实体手机文件接收测试。

| 路径 | 实际操作与结果 |
| --- | --- |
| 现在 | 在 1280×720 按住显眼的行走按钮约 20 秒，松开时计数为 5/6；再次按住约 9 秒后达到 6/6。松开后下一步成为主按钮，场景没有自行跳走。 |
| 解释 | 点击标题下的解释按钮，显示当前路上短句及对应说明；画面停止行走，引导明确提示先读、收起后再长按。最终窄屏实测确认背景浮字隐藏，避免与纸卡重叠。 |
| 之前 | 点击下一步，计数从 0/3 开始。实际长按约 23 秒到达 3/3，松开后突出“接着看：此后”。 |
| 此后 | 三个选项分别进行一次点击，均自动经过有限反馈到达各自三句卡片和结果。过程中不再要求二次确认或按住。 |
| 卡片 → 正文 | 从第一种和第三种卡片点击阅读按钮，正文从顶部打开，并保留各自的选择和结果摘要。没有要求收齐三张卡。 |
| 正文章节 | 点击九章目录中的第五章，目标章节滚到工具栏下方并获得焦点。 |
| 正文 → 卡片 | 关闭正文后返回同一张已完成卡片，保持选中状态，没有重新播放。 |
| 窄屏长按 | 在 390×667 实际按住约 6 秒，计数达到 2/6，松开后停止；解释按钮可点击，展开内容和下一步均可见。 |
| 窄屏卡片 | 发现旧布局会把阅读按钮挤出短屏，改为独立滚动内容与固定底部动作区。在 390×667 实测按钮底边 499px，面板底边 537px；320×568 实测按钮底边 400px，面板底边 438px。两者都能直接点击进入正文；上方卡片可单独滚动阅读。 |

导航始终允许跳看；计数用于引导体验，不作为咨询事实，也不会强制用户走完才允许进入下一步。
