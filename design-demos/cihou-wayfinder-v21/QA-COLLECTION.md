# V21 逐张收集与卡片回看

日期：2026-10-20。沿用 [V21 完整 HTML](final_report.html)，本次只调整通用模板的收集、回看与引导，保留既有画风和三种动画。

## 行为

- 第一次点待收集项，播放对应体验；完整结束后收下这一张，马上可阅读并进入正文。
- 顶部显示已收集数量，各项明确标记待收集、正在体验、已收集。其他卡可以继续收集，不影响一张卡进入正文。
- 点已得卡直接打开它的短句与结果；只有点“重播这段体验”才重新播放。
- 回看已得卡会停止正在进行的另一段体验。未完成的卡仍待收集，旧播放的迟到状态不能误收卡。
- 切换章节或从头体验保留本页卡片；刷新页面重新开始，没有增加账户或本地存储。

## 浏览器实测

在本机 HTTP 预览中真实点击测试，使用桌面与窄屏视口。

| 场景 | 结果 |
| --- | --- |
| 只完成第一项 | 显示已收集 1/3，第一项为“已收集 · 点开看”，其余两项为“待收集 · 去体验”。第一张三句卡与阅读按钮立即可用。 |
| 只有一张时进入正文 | 保留第一项标题和结果摘要，关闭后仍回到第一张。 |
| 第二项进行中点第一张 | 第一张立即显示；收集数仍为 1/3，第二项恢复待收集，没有因被中断而提前获得。 |
| 完成第二项，再切换第一、第二张 | 收集数保持 2/3，两张都直接切换对应内容，界面始终为已完成阅读状态，没有再次进入播放。 |
| 收齐三张后依次点击 1、2、3 | 每次点击后立即显示各自卡片；已收集数保持 3/3，`phase=done`、`reviewingCard=true`，没有进入播放。 |
| 显式重播，然后点当前已得卡 | 先进入播放，再立即取消并回到卡片阅读，数量仍为 3/3。 |
| 390×667 窄屏 | 已得状态和三个入口可辨认，卡片区可独立滚动阅读三句与结果；阅读按钮底边为 499px，面板底边为 537px，按钮保持可见。点击阅读正确带入当前卡片摘要。 |
| 返回“现在”再到“此后”，或从头体验 | 两种操作后均仍为 3/3，点第二张直接进入该卡阅读。 |

## 实现与校验

收藏保存在本页集合中。完成事件同时检查章节、所选项、运行 ID、完成阶段、结果就绪、播放与转场状态；普通回看不会发出播放请求。过期运行状态不能覆盖当前卡片。静态降级仍展示同一份短句与结果并保留可读卡。

自动回归覆盖逐张收集、三张独立回看、未完成跳选、迟到事件、当前卡重播中的直接回看、章节与重走保留、刷新重置、减少动态和引擎失败路径。

`tools/check_workspace.py --skill` 通过：121 项 Skill 测试、6 项评测测试、doctor、Skill 结构、差异格式与本地链接。报告相关回归为 23 项；最终构建及 `build_demo.py --check` 通过。减少动态和失败路径由自动回归验证，本轮未在真实浏览器中强制制造这些环境。
