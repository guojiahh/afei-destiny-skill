# 自适应命理推理协议

这个协议用于减少“见一个十神就下结论”的单点推理。它不是科学验证模型，也不是要求对用户展示全部思维过程。

## 0. 确认问题

先把问题归入：静态特质、领域倾向、关系/六亲、具体事件、时间选择、选项对比。分类要以题目和选项的实际语义为准，不以数据集标签为准；一个选项可能同时包含学历、职业、年份、人物和事件原因。只分析能改变答案的变量。

若同一命主有多道题，先建立一张共享命盘与时间线，再分别作答。各题可以提供明确的前提（例如“有两名子女”），但不能把某一道尚未确定的选项当作另一题的事实。最后做一次时间顺序与人物关系的一致性检查。

## 1. 事实扫描

按以下顺序建立事实表：

1. 日主、月令、司令季节。
2. 天干透出、地支本中余气与通根。
3. 生扶与耗泄克制的结构，不只数五行个数。
4. 合、冲、刑、害、破、伏吟；先看是否实际改变结构。
5. 调候、流通、格局候选；特殊格局必须满足严格条件。
6. 当前大运与目标流年。

把“计算事实”和“解释判断”分开记录。例如“月支为戌、日支为辰，形成辰戌冲”是事实；“家庭/住所更易变动”是解释。

## 2. 结构假设与严重度

最多保留两个主要假设：常格/扶抑解释，以及必要时的调候、从格或化气解释。每个假设用三档严重度：

- **结构性**：月令、日主根基、主格局或大运持续十年，影响面广。
- **触发性**：流年使原局潜在关系成局、冲动关键宫位或换运，影响集中。
- **修饰性**：单一神煞、纳音、孤立口诀，只能微调。

任何重大结论至少需要一个结构性证据，或两个相互独立的触发性证据。单一神煞不得决定答案。

## 3. 病、药与制化

先问命局主要矛盾是什么，再问什么因素能缓解：

- 偏旺：看泄、耗、克是否有根有路，而非机械说“缺什么补什么”。
- 偏弱：看印比是否真能到身，是否反而造成堵塞。
- 两行相战：看通关之神是否存在并有力。
- 寒暖燥湿：调候可优先于简单扶抑，但不能忽略全局承载能力。
- 从格/化格：只有日主无独立根气、全局气势高度一致、逆势力量不足时才考虑；有强根或有力逆神则回普通格局。

## 4. 领域映射

读取 `domain-rules.md` 对应章节。用三类证据交叉：

- 十神：角色与功能。
- 宫位：事情落点。
- 岁运：何时引动。

“十神 = 具体职业/疾病/事件”不是一一对应。先判断功能类别，再用题干现实信息缩小。

同一柱可能有多重语义：日支既是配偶宫，也是日主坐下的生活/身体接口；年月柱既可指父母，也可指早年环境。先根据题目问的是“谁、什么领域、什么年龄”确定语义，再解释合冲，不能看到日支受冲就一律归为婚姻。

## 5. 时间映射

具体年份题读取 `temporal-reasoning.md`。大运决定背景，流年负责触发，原局决定可被触发的议题。没有原局接口的流年信号通常降权。

## 6. 反证与置信度

对首选结论至少做一次反证：

- 是否有更强证据支持相反解释？
- 是否依赖未知时辰、流派口径或一条口诀？
- 是否把结果信息倒灌成命理理由？
- 是否把“可能发生的类别”过拟合成一个极具体事件？

置信度建议：

- **高**：排盘口径稳定；结构、领域、岁运证据一致；反证弱。
- **中**：主方向一致，但时辰/流派/事件粒度存在分歧。
- **低**：关键柱不确定，或多个解释势均力敌。

## 选择题的选项对比

Benchmark 任务先读取 `benchmark-protocol.md`。先独立写出预期的“事件类别/人物功能/时间强弱”，再看选项，防止被选项锚定。逐项使用 0–3 分的内部量表：

- 原局接口：0 无，1 弱，2 明显，3 核心结构。
- 大运背景：0 反向，1 中性，2 支持，3 强支持。
- 流年触发：0 无，1 单点，2 直接，3 多重触发。
- 领域一致：0 冲突，1 宽泛，2 合理，3 高区分。
- 反证惩罚：0 到 -3。

先拆解选项逻辑：

- “A 且 B”“一直如此”“以上年份都有”属于合取命题，每个子条件都要有证据；整项受最弱关键子句限制，任何一个明显不成立就大幅降分。
- “因为赌博/疾病/家人债务而……”包含结果与原因，不能只匹配结果；具体原因需要独立证据。
- “没有发生”是反向题，先对其余各项做正向可能性，再选证据最弱者；不要忘记题干中的否定词。
- 选项若含事实前提（如“有两名孩子”），该前提可用于时间线，但不能反推具体年份或性别。

分数只用于相对排序，不伪装成概率。若两项接近，优先：

1. 需要更少附加假设的选项。
2. 与题干已知人物特征一致的选项。
3. 事件粒度较合理、不含过度戏剧化细节的选项。

再加入两项校准：

- **基准率**：极端、罕见、具体到离奇剧情的选项需要明显强于普通选项的多重证据。
- **时代约束**：教育、职业、婚育与医疗选项要结合命主年龄、地区和当时社会条件；这是现实约束，不是命理证据。
- **细节负担**：两个选项都符合大方向时，包含更多未经支持细节的选项得分更低。

答题后不得根据正确答案反向添加专门口诀到技能。只允许修正可泛化的计算、路由或推理错误。
