丁壬合（木为化神候选）

五合首先只表示关系出现。是否形成牵制、争合或化气，要检查月令、相邻程度、双方原根、化神根气和逆化力量；完整门禁见 `relations-and-transformations.md` 与 `structure-analysis.md`。仅合不化也不自动等于“合绊”。

## 地支关系

### 六冲
子午冲、丑未冲、寅申冲、卯酉冲、辰戌冲、巳亥冲

### 三合局
- 申子辰合水局
- 亥卯未合木局
- 寅午戌合火局
- 巳酉丑合金局

三字齐全只表示组合条件完整，仍需检查月令、透干、根气与冲破。缺一可记半合或拱局候选（如申子、子辰半合水），但没有“力量减半”的通用比例。

### 三会局（方局）
- 寅卯辰会东方木局
- 巳午未会南方火局
- 申酉戌会西方金局
- 亥子丑会北方水局

三会局需三字全见；三会和三合的组织方式不同，不使用“三会必定大于三合”的固定排序。谁主导要看月令、透干、根气和全局用途。

### 六合
子丑、寅亥、卯戌、辰酉、巳申、午未为六合。六合先表示绑定、协作或牵制；各传承对化神，尤其午未，存在差异，本表不直接把配对改写为合化结果。

### 相刑
- 寅巳申三刑（无恩之刑）
- 丑戌未三刑（持势之刑）
- 子卯相刑（无礼之刑）
- 辰辰自刑、午午自刑、酉酉自刑、亥亥自刑

### 相害（相穿）
子未害、丑午害、寅巳害、卯辰害、申亥害、酉戌害

### 相破
子酉破、丑辰破、寅亥破、卯午破、巳申破、未戌破

害与破默认属于低权重关系。寅亥、巳申等配对还同时存在六合名称；关系并存时按全局结构裁决，不做简单相消。

> 本节是关系检测表，不是吉凶断语表。合化、半合、三会、多关系竞争和墓库的后果必须读取 `relations-and-transformations.md`。

## 十神定义及生克关系

### 十神推导规则
以日干（日主）为中心，根据其他天干与日干的五行生克关系及阴阳异同来确定十神：

| 关系 | 阴阳相同 | 阴阳不同 |
|------|---------|---------|
| 生我（我之母） | 偏印（枭神） | 正印 |
| 我生（我之子） | 食神 | 伤官 |
| 克我（克我者） | 偏官（七杀） | 正官 |
| 我克（我制者） | 偏财 | 正财 |
| 同我（同类） | 比肩 | 劫财 |

### 十神详解

| 十神 | 含义 | 代表人事 |
|------|------|---------|
| 比肩 | 同我者，阴阳相同 | 兄弟、朋友、同辈、竞争者 |
| 劫财 | 同我者，阴阳不同 | 姐妹、竞争对手、损财者 |
| 食神 | 我生者，阴阳相同 | 子女（女命）、才华、口福 |
| 伤官 | 我生者，阴阳不同 | 子女（女命）、才艺、叛逆 |
| 偏财 | 我克者，阴阳相同 | 偏财、父（男命）、情人 |
| 正财 | 我克者，阴阳不同 | 正财、妻（男命）、稳定收入 |
| 偏官（七杀） | 克我者，阴阳相同 | 偏权、压力、小人之类 |
| 正官 | 克我者，阴阳不同 | 正权、上级、夫（女命） |
| 偏印（枭神） | 生我者，阴阳相同 | 偏学术、继母、孤独 |
| 正印 | 生我者，阴阳不同 | 母亲、学业、贵人 |

### 五行生克
- 相生：木→火→土→金→水→木
- 相克：木→土→水→火→金→木
