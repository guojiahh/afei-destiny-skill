# 命局结构、格局与用神裁决

本文件补足“知道术语但不会裁决”的缺口。它用于完整咨询、命局强弱/格局/用神问题和需要结构判断的年份题；不用于替代确定性排盘，也不把传统命理包装成统计学模型。

## 一、先分清四条分析轴

同一张命盘可以同时有四类判断，它们回答的问题不同：

| 分析轴 | 回答什么 | 常见术语 | 不能替代什么 |
|---|---|---|---|
| 力量轴 | 日主和各功能能否承载、输出、制约 | 旺衰、得令、得地、得助 | 不能单独决定格局成败 |
| 组织轴 | 月令主气如何组织财官印食杀伤 | 格局、成败、救应、相神 | 不能单独解决寒暖燥湿 |
| 环境轴 | 命局是否过寒、过热、过燥、过湿 | 调候 | 不能把“需要某元素”直接写成发财/升职 |
| 矛盾轴 | 全局最需要疏通、制衡或保护什么 | 病药、通关、制化 | 不能脱离实际根气和岁运 |

输出“喜用”前必须注明是哪一条轴。格局用神、扶抑用神、调候用神和病药/通关之神可能不是同一个字；未完成冲突裁决时，不得压缩成一个万能“喜用神”。

## 二、结构事实卡

任何旺衰、格局或用神判断，先完成以下事实卡。卡片是证据清单，不是机械评分表。

1. **月令与季节**：月支、当令五行、寒暖燥湿背景。
2. **日主根气**：日主在四支是否有本气、中气、余气根；根是否被冲、合、刑或成局改变。
3. **天干显露**：哪些十神透出；透干在地支是否有根、有源、有去路。
4. **生扶链**：印比是否真能到身，还是隔远、受制或被合。
5. **耗泄克链**：食伤、财、官杀是否有根并形成连续功能链。
6. **结构改变**：三合、三会、六合、天干合是否只是出现，还是有条件改变原有力量关系。
7. **主要矛盾**：过旺、过弱、两行相战、寒暖失衡、堵塞或关键功能无承载。
8. **最强反证**：哪一条事实最不支持当前结构假设。

`element_profile` 只能协助发现偏态。固定藏干权重、季节系数和阈值是计算器的透明启发式，不是古籍原定量公式，不能用它覆盖以上事实卡。

## 三、旺衰裁决

### 1. 证据顺序

采用“月令背景 → 根气 → 透藏与功能链 → 制化 → 调候”的顺序。不要把以下任何一项当成单票结论：

- 得令不等于必然身强；失令不等于必然身弱。
- 通根不只数根的数量，还看根的层级、位置和是否受损。
- 印比多不等于一定强，食财官杀多也不等于一定弱。
- 同一种五行出现多次，可能流通，也可能堵塞；要看生克路径。

### 2. 五档表达

只在证据足够时使用：`明显偏强 / 略偏强 / 相对平衡 / 略偏弱 / 明显偏弱`。临界盘允许保留两个候选，不必强行二分“身强/身弱”。

每个档位至少附：

- 两条支持证据，其中一条来自月令或根气；
- 一条最强反证；
- 哪个未知信息或流派口径可能改变结论。

### 3. 假从与假旺

日主看似弱而仍有独立根、有力印比或逆势通道时，先按普通偏弱盘处理；看似旺而已有财官食伤形成有效去路时，也不要轻率归专旺。

## 四、常规格局候选

格局以月令为主要入口，但不等于只看月支本气。先看月令所藏、司令背景、透干与全局能否围绕该功能成链。八格是候选标签，不是命运等级。

| 候选 | 成立时优先检查 | 常见破坏 | 可能救应 |
|---|---|---|---|
| 正官 | 官有根、清而可用，日主能任 | 伤官直接破官、官杀混杂而无裁决 | 财生官、印护官或化官生身 |
| 七杀 | 杀有根且有制化，压力能转为功能 | 杀旺无制、制化两失 | 食神制杀、印化杀、劫刃合杀须看全局 |
| 正印/偏印 | 印能护身、承接官杀或形成学习体系 | 财破印、印多堵塞、枭夺食成链 | 官印相生、食伤有去路、财印位置有情 |
| 食神 | 食神有根、泄秀、生财或制杀 | 偏印直接夺食、泄身过度 | 比印护身、食神生财、制杀有度 |
| 伤官 | 输出功能能生财、佩印或制杀 | 无制见官且形成直接冲突 | 伤官生财、伤官佩印、制杀成链 |
| 正财/偏财 | 财有源、有根，日主或结构能任财 | 比劫争财、财多身不任、财坏关键印 | 食伤生财、官护财、比劫受制 |

月令为比肩、劫财或处禄刃语境时，不要硬塞进八格；按建禄、月劫、羊刃等候选处理，但仍回到“日主承载—泄耗制—功能链”判断。羊刃、魁罡等名称不得越过结构事实直接定吉凶。

### 格局结算格式

```
主候选：〔格局〕
月令依据：〔月令、透藏〕
成格条件：〔已满足〕
破格风险：〔最强破坏〕
救应条件：〔是否存在、能否到位〕
备选解释：〔若有〕
结论粒度：〔结构功能，不写社会等级〕
```

## 五、特殊格局门禁

特殊格局必须比常格承担更高举证责任。只要关键条件不稳，就并列普通结构假设，不得为了“高级”或“少见”强行入格。

### 1. 从格

至少检查：

1. 日主是否缺乏能够独立发挥的根和助力；
2. 全局气势是否高度集中在同一方向；
3. 逆势力量是否无根、受制或不足以自立；
4. 月令和关键地支是否支持所从之势；
5. 合冲成局是否真的改变结构，而非只在名称上“成局”。

有强根、有力逆神或两种气势长期相持时，优先判普通偏弱/偏强，不判真从。证据介于二者之间时标记“从势候选，未结算”。

### 2. 专旺

曲直、炎上、稼穑、从革、润下等专旺候选，要求月令、根气和全局主势一致，且反向制约不能独立成链。三会、三合字面齐全只是候选条件，不自动等于专旺成立。

### 3. 化气

天干出现五合只表示“有合”。进一步论化至少检查：

1. 月令和季节是否支持化神；
2. 化神是否在地支有根、有党；
3. 是否存在强力妒合、争合或逆化力量；
4. 两干各自原有根气是否仍强到足以保持原性；
5. 全局是否实际围绕化神重新组织。

不能完成这些检查时写“合而未证化”或“合绊/牵制候选”，不要直接改写五行属性。

## 六、调候、通关与病药

### 调候

先确认季节环境，再问调候字是否出现、是否有根、是否受保护、是否会带来新的结构代价。冬局见火、夏局见水只是起点，不能机械写成“冬喜火、夏喜水”。

### 通关

两行相战时，通关之神必须同时能承接一方并生化另一方，而且在原局或岁运中能够实际到位。只在理论上存在但无根、受制或隔绝的五行，不算完成通关。

### 病药

“病”是全局最主要、可重复解释多个现象的矛盾；“药”是能缓解该矛盾的结构功能。一个合格的病药判断应能回答：

- 病在哪里；
- 为什么是主要矛盾而不是次要现象；
- 药通过什么路径起作用；
- 药过量、受制或到位太晚时会有什么代价。

| 调候用神 |  |  |  |  |
| 病药/通关 |  |  |  |  |

裁决顺序：

1. 先排除没有根、没有路径或会直接破坏核心结构的候选。
2. 再看哪个候选同时解决主要矛盾并保留原局可用功能。
3. 若调候与格局方向不同，分别保留“环境可用性”和“社会功能组织”结论，不强行压成同一喜忌。
4. 只有多个轴同向时，才可称“共同喜向”；仍不把颜色、行业、方位等现实标签写成保证。

## 八、与岁运结合

原局结构先锁定，大运流年只回答“哪一候选功能在何时获得根、透出、被冲开或受损”。岁运不能倒过来证明原局一定属于某格。

- 大运使主候选成立：写“该阶段更接近……的运行方式”。
- 大运使备选假设胜出：记录结构切换条件，不重写出生盘事实。
- 一年只出现候选字但没有原局接口：降为短期主题。
- 需要具体事件时，再读 `temporal-reasoning.md` 和相应领域规则。

## 九、自检

提交结构判断前检查：

- 是否把启发式分数当成最终旺衰？
- 是否把“有合”直接写成“已化”？
- 是否把格局名称写成社会等级或必然事件？
- 是否区分了四种用神语义？
- 是否给出了最强反证和未结算条件？
- 去掉用户经历后，结构结论是否仍能从命盘事实复现？
