# 干支关系、合化与墓库裁决

本文件用于纠正“计算器检测到一个关系，模型就直接翻译成事件”的错误。计算器负责报告关系是否出现；本文件负责判断它有没有改变结构、落到哪个领域、能支持多大粒度的结论。

## 一、四层关系模型

任何合、冲、刑、害、破、会局，都分四层处理：

1. **检测层**：哪些字之间存在传统关系名称。
2. **参与层**：关系是否相邻、重复、跨原局/大运/流年，相关字有没有根气。
3. **结构层**：关系是否改变了原有功能链、根气、月令主势或关键宫位。
4. **事件层**：改变通过哪个十神、宫位、人物和时间阶段落地。

只完成第 1 层时，只能写“存在关系”；不能写“必然合化、离婚、发财、开库或遭灾”。

## 二、天干关系

### 五合

甲己、乙庚、丙辛、丁壬、戊癸相合，先记为“有合”。进一步检查：

- 是否相邻或有直接作用路径；
- 双方是否各有强根，形成牵制而非改变属性；
- 是否有第三干争合、妒合；
- 月令是否支持化神；
- 化神是否有根、有党并能主导全局。

结算只用三档：

- **关系出现**：检测到五合，尚未判断后果；
- **牵制/绑定成立**：双方功能被拉住或形成合作接口，但未证化；
- **化气候选成立**：通过 `structure-analysis.md` 的化气门禁，仍需说明证据和反证。

“不化”不自动等于“合绊”。合绊是结构后果，需要说明哪项功能被牵制、为什么无法正常发挥。

### 天干冲克

计算器区分天干层与地支层。天干相冲或相克更接近显露功能之间的冲突，不得误写成地支六冲带来的根基/宫位直接变动。是否构成严重问题仍看双方根气、制化与所问领域。

## 三、地支组合

### 三合与三会

三字齐全表示组合条件完整，不等于无条件改变全部五行属性。继续检查：

1. 月令是否支持组合方向；
2. 化神是否透出或有明确承接；
3. 组合成员是否受强冲、受制或被其他结构争夺；
4. 成局后是否真的改变日主根气和目标功能链。

三会与三合是不同组织方式，不能使用“见三会就一定强过三合”的固定排序。谁主导要回到月令、透干、根气和全局用途。

### 半合与拱局

两字只表示聚势候选。禁止写“力量减半”之类伪精确比例。判断时记录：

- 是否包含中神；
- 第三字在大运或流年是否补齐；
- 补齐后是否仍通过成局条件；
- 未补齐时，它对当前问题只是修饰、牵引还是已形成局部功能链。

### 六合

六合先表示绑定、协作、牵制或关系接口。各传承对化神，尤其午未，存在差异；本技能不把六合对照表直接当成合化结果。

六合落到事件层前问：

- 合住的是可用功能还是主要矛盾；
- 是引入、保护、争夺、迟滞还是改变归属；
- 在关系题中属于相识、绑定、共同生活还是法律落地；
- 是否同时存在冲、刑、破等关系，形成“合中有变”。

## 四、冲、刑、害、破

### 六冲

六冲优先表示变化、位移、对立或原有连接被打破。方向不预设吉凶：

- 冲去病神可能释放功能；
- 冲动用神、根气或关键宫位可能形成压力；
- 冲开停滞结构可能对应迁移、转岗、交易或关系重组；
- 单年冲动通常先支持“变化窗口”，不直接支持终局。

### 刑

刑表示持续摩擦、内部不协调或重复压力的候选。三刑要检查成员是否齐全，自刑要检查同支是否真实重复及其所在层级。不能只见一个“刑”字就断伤灾、官非或疾病。

### 害与破

害、破的解释分歧较多，默认低于直接六冲、完整三合三会和有根透干的十神功能链。只有它们与目标宫位、角色星和岁运重复同向时，才作为辅助证据。

相破常见配对：子酉、丑辰、寅亥、卯午、巳申、未戌。同一对字可能同时拥有六合等其他名称；并存时不能简单相互抵消，要说明哪种结构后果在当前全局更可见。

## 五、多关系竞争

同一字同时参与多个关系时，不得全部算满：

1. 先按月令、根气和相邻程度找主关系；
2. 再看大运流年是否使某一关系获得完整成员；
3. 同一事实只计一次，不用“关系数量”制造多重证据；
4. 两种关系都可能成立时，分别写条件和事件阶段，不强行选一个固定吉凶。

典型错误：日支既被合又被冲，就写成“先婚后离”。正确做法是先判断关系/生活结构在该阶段更容易被绑定还是改变，再用配偶星、连续岁运和题目阶段缩小。

## 六、辰戌丑未与墓库

辰、戌、丑、未兼具季末土、藏干和传统墓库语义。处理时分开：

- **土性与季节背景**：先按月令、燥湿和根气分析；
- **藏干容器**：记录其中哪些功能存在，但不等于已经可用；
- **冲动变化**：冲可能使藏干议题显露，也可能损伤原有根基或造成土势相战；
- **事件映射**：必须落到具体十神、宫位和岁运，才谈资源、房产、家庭、身体等领域。

禁止规则：

- “见辰戌冲/丑未冲 = 开库”；
- “冲财库 = 必发财”；
- “墓库多 = 一定迟滞/孤独”；
- 把任何一个辰戌丑未自动叫作命主财库。

若要写“库被引动”，至少说明：库中什么功能与问题有关、冲动后由谁承接、日主/全局能否使用，以及最强反向结果是什么。

## 七、原局、大运、流年中的关系

同一关系在不同层级的含义不同：

| 位置 | 主要作用 |
|---|---|
| 原局内部 | 长期结构与潜在接口 |
| 大运—原局 | 十年背景持续改变某一接口 |
| 流年—原局 | 短期直接触发 |
| 流年—大运 | 当年与十年背景是否同向、接力或冲突 |
| 原局—大运—流年成局 | 三层共同完成结构改变，权重较高 |

完整矩阵仍不是合冲计分器。先锁定目标角色和领域，再比较关系是否真正作用于该接口。

## 八、事件粒度门禁

| 证据 | 最大建议粒度 |
|---|---|
| 单一关系名称 | 有变化/牵制/聚势候选 |
| 关系 + 目标宫位/十神 | 某领域明显被引动 |
| 原局接口 + 大运背景 + 流年直击 | 重要阶段或事件类别 |
| 多层同向 + 连续时间 + 角色证据 | 可比较更具体阶段，但仍不保证唯一剧情 |

死亡、严重疾病、犯罪、破产、离婚终局等高负担结论，不能由一个冲刑合害推出。真实咨询中保持风险语言；Benchmark 被迫比较时也要执行基准率和复合子句门槛。

## 九、关系裁决卡

```
检测事实：〔哪几个字、哪一层〕
参与条件：〔相邻/根气/补齐/重复〕
结构后果：〔改变了什么；若未改变写未证〕
目标接口：〔十神 + 宫位 + 角色〕
时间阶段：〔背景/触发/落地/终止〕
最强反证：〔另一种可能后果〕
允许粒度：〔主题/领域/阶段/具体类别〕
```

## 来源边界

本文件综合传统子平的关系语言与本项目错题审计，采用的是可执行的保守裁决，不把任何一部古籍的断语当成统计规律。可核对入口：

- 《三命通会》四库全书本：<https://zh.wikisource.org/zh-hans/三命通會_(四庫全書本)>
- 《渊海子平》：<https://zh.wikisource.org/wiki/淵海子平>
- 《神峰通考》：<https://zh.wikisource.org/wiki/神峰通考>
- 《滴天髓阐微》：<https://zh.wikisource.org/zh-hant/滴天髓闡微>

其中关于动静、墓库、合化等说法本身也有传承差异。本技能只把它们作为结构候选，通过月令、根气、透干、制化和岁运复核后才进入结论。
