# 经典来源与规则边界

这不是“熟读九部古籍”的装饰性书单，而是一个来源注册表。引用时区分原文、后世注解与本技能的现代归纳；没有核对到篇章的句子不要加书名号冒充原文。

## 来源层级

1. **历法事实**：以确定性计算器为准，不让口诀代替节气和干支计算。
2. **子平核心**：月令、日主、十神、格局、制化、岁运。
3. **调候与气势**：用于修正纯粹扶抑判断。
4. **神煞、纳音、宫位年龄段**：辅助层，不独立定重大事件。
5. **七政四余、择日、风水等其他体系**：不混入本技能的八字主推理。

## 《三命通会》

可用范围：十神、财官、格局、干支关系与古代命例。四库本卷十有“以日干为主”、财官根气与岁运并看的论述，可支持以下归纳：

- 日干是关系坐标，但不能脱离月令和地支根气。
- 财官印食是否可用，要看有根、透出、制化和日主承载。
- 大运流年不是另起一盘，而是作用于原局已有结构。

来源：

- 维基文库《三命通会》四库全书本卷十：<https://zh.wikisource.org/zh-hant/三命通會_(四庫全書本)/卷10>
- 维基文库《三命通会》卷一：<https://zh.wikisource.org/zh/三命通會/卷一>

使用限制：书中大量断语带有古代社会结构和命例选择偏差。转成现代领域时只保留功能关系，不照搬等级、性别和寿夭断语。

## 《滴天髓》及《滴天髓阐微》

可用范围：五行气势、源流、旺衰的动态理解、制化与反局。

- 看气从何来、向何处流、在哪里受阻，比单纯计数更重要。
- 旺衰不是“得令即旺”的一票决定；根、助、泄、制和全局气势共同作用。
- 合冲的结果取决于双方强弱与全局用途，同一冲可破坏也可解局。

来源：

- 维基文库《滴天髓》：<https://zh.wikisource.org/wiki/滴天髓>
- 维基文库《滴天髓阐微》：<https://zh.wikisource.org/wiki/滴天髓闡微>

使用限制：任铁樵注与原文不是同一时代、同一层级；引用时写“《滴天髓阐微》任氏注”而不是全部归为原典。

## 《子平真诠》体系

可用范围：以月令取用、格局成败救应、用神与相神的关系。

- 先提出格局候选，再检查透藏、有情无情、成败与救应。
- “用神”在格局语境与扶抑、调候语境可能不是同一个概念，输出时必须说明采用哪一种。
- 格局清纯不等于人生所有领域都好；只说明结构协作度较高。

使用限制：不同传本和注家对用神术语差异明显。技能不把某一现代讲法伪装成唯一古法。

## 《穷通宝鉴》

可用范围：十干十二月的寒暖燥湿与调候优先级。

- 夏局并非一概喜水、冬局并非一概喜火；要看日干、全局承载和调候字是否有根有护。
- 调候解决环境可用性，扶抑解决力量关系，格局解决功能组织，三者不可混成一个分数。

来源：维基文库《穷通宝鉴》：<https://zh.wikisource.org/zh-hant/窮通寶鑑>

## 《渊海子平》《神峰通考》

可用范围：十神、基本格局、病药与辨谬。

- 十神是相对日主的功能关系，不是固定人格标签。
- 病药法先找全局主要矛盾，再找能通关、制化或调候的因素。
- 反对只凭神煞或单句歌诀做完整结论。

使用限制：若未核到具体卷章，只能写“依子平体系的通行归纳”，不要杜撰引文。

## 神煞的低权重使用

神煞只能做修饰性证据。常见起例可用于复核：

- 天乙贵人通行口诀：甲戊庚见丑未，乙己见子申，丙丁见亥酉，壬癸见卯巳，辛见寅午。
- 驿马：申子辰见寅，寅午戌见申，巳酉丑见亥，亥卯未见巳。
- 咸池：申子辰见酉，寅午戌见卯，巳酉丑见午，亥卯未见子。
- 华盖：申子辰见辰，寅午戌见戌，巳酉丑见丑，亥卯未见未。

神煞必须与十神、宫位、岁运同向才加权；不能用“贵人”保证好运，也不能用“劫煞”断灾。
