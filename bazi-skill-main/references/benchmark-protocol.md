# 命理选择题与 Benchmark 协议

本协议只规定解题过程，不包含任何数据集答案、人物传记或题号规律。目的不是把推理写得更长，而是减少单一口诀、戏剧化选项和同案例循环自证造成的误判。

## 1. 建立案例档案

同一命主有多题时，先保留一份共享档案：

- 题给四柱、性别、出生背景和明确事实；
- 日主、月令、根气、透藏、关键合冲与两种以内的结构假设；
- 各步大运及候选流年的干支；
- 已由题干确认的教育、家庭、事业、关系节点；
- 尚未确认的候选人物模型，最多两个，必须标记为假设。

每题先独立评分，再用已确认事实检查一致性。上一题的预测不是事实，不能作为下一题证据；跨题一致性只作小幅校准，不能把一套顺口的人物故事循环证明成答案。

## 2. 按实际语义路由

不要以数据集 `category` 代替问题理解。先读题目和所有选项，标记每个选项实际包含的维度，例如：

- 静态结构：性格、能力、关系模式；
- 现实落点：学历、职业、行业、婚姻状态、子女；
- 时间：年龄段、大运、具体年份；
- 角色：本人、伴侣、父母、子女、同辈；
- 原因与结果：事故方式、负债原因、离职原因；
- 严重度：普通变化、明显转折、长期重创。

一个选项可能同时跨越多个维度。所需资料按实际语义加载，不按标签只读一个领域章节。

## 3. 证据优先级与早停

Benchmark 按以下优先级处理证据：

1. 任务格式与题目逻辑；
2. profile、题干及同案例题干明确陈述的事实；
3. 文本语义、时间顺序、人物关系与现实约束；
4. 确定性历法及排盘事实；
5. 原局—大运—流年共同支持的强命理信号；
6. 单一十神、单一合冲刑害、神煞、纳音或孤立口诀等弱信号。

“明确事实”只包括题目实际断言的内容，不包括选项、上一题预测、由匿名线索猜出的身份、外部传记记忆或由命理反推的经历。

先做文本证据闸门：

- 题干已明确给出所问年份、事件、人物关系或结果，且只有一个选项的所有关键子句与之完整一致：直接选择并停止，不排盘。
- 通过否定词、语义拆句、时间顺序或人物关系能唯一排除到一个选项：只做局部一致性检查后停止。
- 文本证据仍留下两个以上合理候选：只扫描能够区分这些候选的命盘变量。
- 只有具体年份、事件阶段或相近选项仍无法区分时，才运行完整运年矩阵与三路径复核。

命理证据用于补足题干未说明的部分，不用于否认无歧义的题干事实。弱命理信号不得推翻明示事实；若二者冲突，应降低命理解释置信度或标记题目内部不一致。题干若使用假设、引述、否定或待判断语气，先做文本一致性审计，不能把它误当成硬事实。

精确历史年份、亲属生卒、任职名称等客观事实不能由八字可靠地产生。真实用户若明确要查证且工具可用，应转为权威来源检索并把事实核验与命理解读分开；纯 Benchmark 禁止搜索答案时，只能在给定证据内低置信度比较，不能用伪精度补全人物传记。

## 4. 双阶段系统：隔离 BASE 与专家审计

结构化协议在不同题型上可能有益，也可能因过度推理而覆盖模型原本正确的判断。真正独立的直接候选必须在没有读取本技能的上下文中产生，不能要求已经读过规则的同一上下文“假装没读过”。

### 阶段一：隔离的直接候选

若运行环境支持隔离子代理，批量 Benchmark 默认先启动一个不读取本技能、参考文件和脚本的干净代理。它只看答案已剥离的题包，依据题面、现实逻辑和模型原有知识输出每题 `BASE` 候选；禁止搜索答案、人物识别、题号或字母分布捷径。

高预算评测可让三个彼此隔离的直接代理作答并逐题聚合；重复运行属于同一个方法族，不因“票多”自动压过专家证据。若没有隔离能力，才在加载领域细则前记录 `BASE + backup + confidence`，并明确这是相关性更高的退化方案。

### 阶段二：专家挑战

读取技能后，把 BASE 当作默认答案。只检查最可能改变它的计算事实、目标领域接口、关键大运流年和最强反证；不得重新编造一套更长的人物故事。

每次换票必须写出内部 `switch certificate`，并同时满足：

1. BASE 的区分性必要子句存在题干事实、确定性排盘或同等级结构证据的明确反证；
2. 挑战项的角色归属正确；
3. 事件领域和阶段正确，未把机会、变化、危机、分居、终止互相替代；
4. 年份题同时具备原局目标接口、大运同向背景、流年直接触发；
5. 上述证据覆盖挑战项与 BASE 之间真正不同的子句，而不只支持二者共有的大方向；
6. 挑战项所有高负担必要子句均获支持；
7. 没有使用另一题的预测、人物身份猜测或外部答案记忆。

缺一项就保留 BASE。若两个候选都含无依据的必要子句，重审全部选项，允许选择第三项，而不是在二者之间强行投票。

对婚姻段数、性取向、谁出轨、子女性别/精确数量、亲属生卒、具体职业/外貌/疾病/事故原因等低可识别细节，专家默认不接管。对排盘事实、结构功能链、财务承载、学业阶段和唯一的岁运复合触发，才允许更高审计权重。这是按可识别性调节门槛，不是按数据集标签记答案。

## 5. 先形成不看选项的预期

在逐项比较前，先用一句内部摘要写出：

`目标角色 + 目标领域 + 结构倾向 + 大运背景 + 可能触发方式 + 可识别粒度`

命盘先映射到功能轴，不直接跳到具体名词：

- 制度型 / 经营型；公开型 / 幕后型；
- 技术型 / 表达型；体力型 / 抽象型；
- 稳定积累 / 机会波动；建立 / 变化 / 终止。

十神或五行不能单独等同某个职业、专业、疾病、外貌、装修风格或剧情。

## 6. 完整时间关系矩阵

凡题目涉及“后来、目前、某年、哪步运、几岁”，对每个候选时间强制检查：

1. 原局与大运：十年主题、结构的病药变化、目标宫位是否长期被引动；
2. 原局与流年：流年是否直接触发目标十神、宫位或既有结构；
3. 大运与流年：岁运之间的合冲刑害、伏吟反吟、天干功能关系；
4. 三方成局：流年是否补齐原局与大运的三合、三会、刑局或使结构实质改变；
5. 时间语境：实际起运边界、命主年龄、事件合理顺序和前后年份连续性。

先由大运确定十年主题，再由流年判断触发方式。不能因为一个流年冲刑最醒目，就跳过大运和事件接口。

## 7. 事件接口与状态机

合、冲、刑、害先表示绑定、改变、压力或失衡，不直接表示结婚、离婚、死亡、犯罪、破产或无子。先问：这个信号通过哪个十神、宫位和年龄语境落到谁、哪个领域？

关系题按阶段区分：

`相识/机会 → 交往/绑定 → 登记/婚姻落地 → 危机显化 → 分居 → 法律终止或复合`

配偶星出现偏向机会，配偶宫被合可表示绑定，冲动可表示关系或生活结构改变；这些阶段不能互相替代。判断谁出轨、谁施暴、谁提出结束，需要额外的角色归属和行为链证据。

学业题按阶段区分：

`学习能力 → 教育资源 → 入学层级 → 持续完成 → 专业方向`

印官支持学习或进入体系，不自动推出完成大学；家庭资源、学龄期岁运和中断信号决定现实学历。

财运题区分“出现财务机会”和“能够承载、留住财富”；子女题区分“子女星出现”和“有承载且子女宫稳定”。

## 8. 逐候选、逐子句评分

每个选项拆成最小可验证子句，按同一尺度比较：

- 原局接口：0–3；
- 大运背景：0–3；
- 流年直击：0–3；
- 岁运复合/成局：0–3；
- 角色与年龄语境：0–2；
- 强反证：0 到 -3；
- 无依据细节负担：0 到 -3。

合取选项受最弱关键子句限制。一个命中点不能抵消两个无证据的职业、原因、人物或年份细节。罕见职业、具体疾病、暴力、犯罪、死亡、破产等高负担断言，至少需要两个相互独立的接口；否则优先选择粒度适当、附加假设更少的选项。细节负担可以阻止一个新挑战项，却不能单独成为推翻 BASE 的证据。

不要找到第一个“说得通”的选项就停止；所有候选项必须横向使用同一标准。

## 9. 三路径内部复核

只有专家审计已经发现足以挑战直接候选的强证据、且选项仍相近时，才做三个内部判断：

- **结构路径**：月令、根气、格局、病药、十神功能链；
- **时间/角色路径**：宫位、六亲、原局—大运—流年矩阵、事件阶段；
- **选项审计路径**：逐子句反证、现实时间约束、基准率和细节负担。

两个路径指向同一选项时，再检查它是否完整通过 `switch certificate`；通过才替换 BASE。三个结果各异时保留 BASE，除非其中一个选项由确定性事实唯一推出。简单事实题无需机械重复三遍。

## 10. 最终一致性检查

提交前只检查四件事：

1. 是否把冲刑直接翻译成终局；
2. 是否漏掉大运与流年的直接关系；
3. 是否接受了带无依据细节的复合选项；
4. 是否用自己的上一题预测循环支撑本题。
5. 是否只因专家故事更长、更像术语而推翻了证据尚可的直接候选。
6. 每次换票是否有完整的 `switch certificate`，并真正覆盖两个选项的区分子句。

批量评测要求只输出字母时，推理留在内部，不附解释、编号或 Markdown。
