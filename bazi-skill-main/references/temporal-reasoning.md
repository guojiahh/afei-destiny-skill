# 岁运与事件时间推理

## 三层时间模型

1. **原局**：可被触发的主题与承载方式。
2. **大运**：约十年的背景、资源和主要矛盾。
3. **流年**：把背景落实为某类变化的触发器。

没有原局接口时，流年孤立的合冲只给低权重。大运与原局形成长期结构、流年再次引动同一节点时，权重最高。

先区分天干与地支层：天干相冲是功能显露层的冲突，地支六冲才是根基/宫位层的直接变动。半合、拱局只是可能的聚势，未满足月令、透干和全局条件时不得写成“已经合化”。

## 先定位大运

使用计算器 `luck_cycles.primary`，不要凭年龄整十年猜。换运年允许前后盘气交叠；如果两种起运法跨年度，明确列为口径不确定。

大运分析顺序：

1. 运干、运支相对日主的十神功能。
2. 与原局是否合成/冲开关键结构。
3. 是否强化命局的病或药。
4. 对所问领域是否有直接接口。

## 完整运年矩阵

年份或年龄段选择题不能只读取计算器中的“流年与原局关系”。对每个候选时间都要补齐：

- 原局 ↔ 大运；
- 原局 ↔ 流年；
- 大运 ↔ 流年；
- 原局、大运、流年是否共同补齐三合、三会、刑局或持续攻击同一接口。

同一关系只计一次，不用合冲数量代替证据质量。先确定目标领域的十神、宫位与角色，再比较矩阵；否则最醒目的冲刑可能被错误分配给婚姻、家庭、身体或事业。

## 流年触发强度

从强到弱可参考：

- 岁运与原局对同一柱形成复合触发。
- 流年伏吟/反吟关键柱，或冲合日支、月令、时柱等目标宫位。
- 原局已有半合/会/刑，流年补齐。
- 流年透出关键十神且在地支有根。
- 单独出现神煞、纳音或无根天干。

合不总是吉，冲不总是凶：合可能绑定、迟滞或被夺；冲可能破坏，也可能冲开库、推动迁移。必须看被改变的是什么。

## 事件严重度与粒度

- 只有单一流年信号：描述为短期主题或小事件。
- 大运背景 + 一处直接触发：描述为明显变化窗口。
- 原局接口 + 大运放大 + 流年多重触发：可描述为重要转折，但仍给事件类别而非唯一剧情。

不要从“父母宫受冲”跳到“父亲去世”。先给家庭/父母/住所变化类别；只有选择题强制比较具体选项时，再用六亲星、年龄、其他触发作区分。

严重事件选项要检查前后连续性。单年强冲更常对应转折或显化；若选项包含长期重病、破产、死亡等持续后果，优先寻找连续两年以上的叠加、换运、岁运并临或同一结构反复受击。不要因为某年合冲数量最多就自动选最严重剧情。

若一个选项同时包含多个领域（例如配偶失业、本人创业、子女冲突），要求对应的多个功能星/宫位同时被激活；这类复合叙事不应由单一冲合支持。求财、购房、工作落地等题，直接出现且有根的财/官/印功能通常高于“冲库即发财”等间接象意。

## 年份选择题流程

1. 不看选项先列每个候选年的干支和所在大运。
2. 针对所问领域，确定关键十神与宫位。
3. 比较每年是“出现”“引动”还是“改变结构”。
4. 检查连续年份：事件常有酝酿、发生、善后三阶段；题目问结婚、迁居等正式节点时，优先能形成落地/绑定的年份。
5. 用题干给出的既往事实校准结构解释，不用答案校准。
6. 同一命主有多道年份题时，做时间线一致性检查：结婚、子女、职业变化的先后关系应现实可行，但不要把猜测循环证明。

关系年份要区分：桃花/官财出现是“遇见”，冲配偶宫常是“改变或分离”，合与伏吟也可能是“绑定、登记或重复议题”。正式结婚优先寻找配偶星有根、配偶宫被绑定、且大运支持落地的组合；不能只选合冲最多的一年。

## 历史回溯

回溯的目的不是冷读，而是检查解释能否泛化。选择 2–3 个强触发窗口，每个给：

- 年份或两年窗口。
- 可能领域（工作/关系/迁移/家庭/健康之一到两个）。
- 命理触发机制。
- 明确询问用户是否吻合。

用户反馈不吻合时，优先检查出生时间、换日、真太阳时和起运法，再考虑修改格局假设。不要为了迎合反馈无限改写。
